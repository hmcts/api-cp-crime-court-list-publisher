# api-cp-crime-court-list-publisher

OpenAPI specification for the Common Platform Crime Court List Publisher API.

## API documentation

The API documentation is published online as Swagger UI:

**https://hmcts.github.io/api-cp-crime-court-list-publisher/**

The [Publish API docs](.github/workflows/publish-api-docs.yml) workflow republishes it whenever a GitHub release is published. You can also run the workflow manually.

## OpenAPI specification

The spec is at [src/main/resources/openapi/court-list-publisher.openapi.yml](src/main/resources/openapi/court-list-publisher.openapi.yml).
